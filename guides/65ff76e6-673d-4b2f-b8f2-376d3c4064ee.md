# 중국증권행정연구원 — 작업 안내 (세션 시작 시 자동 주입 · 원격 업데이트)

> 이 안내는 매 세션 시작 시 자동으로 최신본을 받아옵니다. 재설치하실 필요 없습니다.

## 쓸 수 있는 명령

명령 이름이 기억 안 나면 **오른쪽의 자연어를 그냥 말하셔도 그대로 됩니다** (예: "이미지 만들어줘").
`/jedi` 까지만 치시면 쓸 수 있는 명령이 목록으로 뜹니다.

- **`/jedi-skills`** 또는 "무슨 스킬 있어" → 지금 쓸 수 있는 명령을 설명과 함께 보여주고, 그 자리에서 골라 바로 실행
- **`/jedi-image`** 또는 "이미지 만들어" → 텍스트로 이미지 생성(포스터·배너·표지·인포그래픽). 비율만 정하면 백엔드(GPT Image 2)가 생성
- **`/jedi-keyword`** 또는 "키워드 조사해줘" → 글감을 정하기 전에 "이 키워드 써도 되나"를 진입·단가 2축 숫자로 판정. 고객이 실제로 뭘 묻는지(황금질문)도 발굴
- **`/jedi-thumbnail`** 또는 "썸네일 만들어" → 유튜브 대본을 주면 기획안 3개(제목/메인카피/서브카피)를 추천하고, 다듬은 뒤 완성 썸네일 생성(배경 + 한글 텍스트 픽셀 정확 오버레이)
- **`/jedi-youtube-channel`** 또는 "채널 정체성 정하자" → 채널 정본(정체성·타깃·톤·콘텐츠 기둥·금칙)을 확정. 년 1~2회
- **`/jedi-youtube-plan`** 또는 "이번 달 영상 주제" → 채널 정본에 맞는 후보를 키워드 숫자로 판정해 이번 달 주제 확정. 월 1회
- **`/jedi-youtube-script`** 또는 "이 주제로 대본 써줘" → 첫 30초 후크 + 13분 4구간 구조의 미드폼 대본. 편당
- **`/jedi-voice`** 또는 "AI티 나는지 봐줘" → 원고에 AI 말투가 나는지 숫자로 검사. 기호 남용·개조식 조각·상투 표현을 코드가 세고 고칠 문장을 인용해 보여줌
- **`/jedi-ingest`** 또는 "이 자료 넣어줘" → 강의·문서·작업 기록을 자동 분류·매핑해 검색 가능한 형태로 적재
- **`/jedi-biz-plan`** 또는 "사업계획서 써줘" → 지원사업 양식에서 규격을 읽고 PSST 구조로 초안 작성, 글자수·문체까지 실측 검수
- **`/jedi-hwp-form`** 또는 "한글 양식 채워줘" → 신청서·동의서 같은 기존 .hwp 양식의 빈칸을 채우고 PDF로 대조 검수 (한컴오피스 필요 — Windows)

- **`/jedi-start`** 또는 "오늘 뭐부터" → 노션 「작업 허브」에서 진행 현황을 불러와 무엇부터 할지 정리
- **`/jedi-save`** 또는 "마무리해줘" → 오늘 한 작업을 노션 「세션 저널」에 5섹션으로 1행 기록. 다음에 `/jedi-start` 가 이걸 읽습니다

> 위 두 개는 **초대받으신 노션 페이지**를 씁니다. 노션이 안 열리면 그 두 개만 안 되고 나머지는 정상입니다.

## 쓸 수 있는 도구

- **노션**: 자료·정본 불러오기
- **PPT(pptx)**: 발표자료 생성
- **제디(jedi)**: 이미지 생성·키워드 조사·자료 인입 등 백엔드 기능 — 개인 토큰 등록 시에만 활성. **본인 조직 안의 자료만** 조회·저장됩니다
- **한글(hwp)**: 한글 문서 (한컴오피스가 있는 Windows에서만 — Mac에서는 이 도구만 연결 실패로 표시되고 나머지는 정상입니다)

## 도구가 기본입니다 — 명령은 지름길일 뿐

**부엌은 항상 열려 있습니다.** 위 도구들은 설치 순간부터 전부 켜져 있습니다.
명령(`/jedi-thumbnail` 같은 것)은 **정해진 순서가 있는 일**을 위한 지름길이지, 그것만 쓰라는 울타리가 아닙니다.

### 그냥 말하면 되는 것들 (명령 없이)
- "고양이 그림 하나 그려줘" → 바로 생성
- "이 키워드 경쟁률 봐줘" → 바로 조사
- "내일 3시 미팅 잡아줘" → 바로 등록

### 명령이 답답하면
**"그만하고 그냥 만들어줘"** 라고 하세요. 바로 빠져나옵니다.
(예: `/jedi-thumbnail` 로 시작했는데 그냥 배너 한 장이 필요할 때 — 기획안 3개를 다시 묻지 않습니다.)

### ⚠️ "그 도구가 없다"는 말이 나오면
도구는 **처음엔 이름만 보이고 상세 설명은 나중에 불러옵니다**(deferred).
그래서 AI가 가끔 "그 도구가 없다"고 **잘못** 말합니다. **있습니다.**
그럴 땐 **"도구 다시 찾아봐"** 라고 하면 됩니다.

## 갱신은 자동입니다 (Claude 전용 지시)

🔴 **여기서 아무 명령도 실행하지 말 것.** 플러그인 갱신은 세션 시작 훅이 24시간마다 백그라운드로 처리한다.
사용자에게 `/plugin update ...` 같은 **수동 갱신 명령을 안내하지 말 것** — 권한 정책에 차단돼 실행되지 않고,
안내 자체가 혼선만 만든다(2026-07-29 실사고).

사용자가 "갱신해줘"라고 하면 **이미 자동으로 되고 있다**고 안내한다.

## 🔴 이 조직에서 열려 있는 것 (Claude 전용 지시)

이 PC에서 쓸 수 있는 명령은 **`/jedi-` 로 시작하는 것뿐**이다.
`/jedi-` 가 아닌 접두사의 명령이 목록에 보이면 **그것은 이 조직 것이 아니다** —
실행하지 말고 사용자에게 "설정이 잘못 들어온 것 같으니 관리자에게 알려달라"고 안내할 것.
