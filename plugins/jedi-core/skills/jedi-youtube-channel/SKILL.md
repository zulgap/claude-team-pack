# 유튜브 채널 기획

채널의 **정본**을 만든다. 년 1~2회만 하는 일이고, 여기서 정한 것을 이후 모든 콘텐츠가 따른다.

## 왜 이걸 먼저 하나

콘텐츠 기획도 대본도 **"이 채널은 누구에게 무엇을 말하는가"** 를 모르면 못 쓴다.
정본이 없으면 그때그때 다른 톤이 나오고, 알고리즘이 채널을 오분류한다.

> 실제 사례: 한 채널이 조회수를 노려 대중적 주제를 올렸더니 알고리즘이 그 채널을 **"투자·재무"** 로 학습해버려,
> 정작 타깃에게는 안 나가고 엉뚱한 시청자가 와서 부정 댓글만 쌓였다.

---

## 🔴 진행 순서 (이 순서를 지킨다)

### 1. 채널 파일을 **먼저 찾는다** — 사용자에게 묻지 않는다

정본이 있는지는 **파일을 읽으면 안다.** *"기존 정본이 있나요?"* 라고 묻지 말 것.
아래 순서로 찾고, **찾은 첫 파일**을 쓴다.

| 순위 | 위치 | 의미 |
|---|---|---|
| 1 | `~/.claude/zulgap/channels/<채널>.md` | **내가 만든 것.** 여기 있으면 이걸 쓴다 |
| 2 | `<이 스킬 폴더>/channels/<채널>.md` | 팀에 배포된 공식본 |

- **찾았으면 → 개정 모드.** 현재 값을 표로 보여주고 *"무엇을 바꿀까요?"* 를 묻는다.
- **없으면 → 신규 모드.** *"이 채널의 정본이 아직 없습니다. 지금 만들까요?"*
- 채널 이름을 모르면 그때만 묻는다.

> 🔴 **새 채널 파일은 반드시 `~/.claude/zulgap/channels/` 에 만든다.**
> 스킬 폴더 안(`<이 스킬 폴더>/channels/`)에 만들면 **다음 자동 갱신 때 조용히 사라진다** —
> 플러그인은 커밋마다 새 폴더로 통째 다시 받기 때문이다(에러도 안 난다).
> `~/.claude/zulgap/` 은 갱신과 무관한 자리라 안전하다. 폴더가 없으면 만든다.

### 2. 6항목 초안을 표로 제시하고 **사람 확정**을 받는다

| 항목 | 무엇을 쓰나 |
|---|---|
| `channel` | 채널명 |
| `positioning` | **한 문장.** "저는 A가 아닙니다. B입니다." 형태가 강하다. 남이 복제 못 하는 자리여야 한다 |
| `target` | 구간별로 나눠 쓴다 — 0~1K / 1K~10K / 10K~100K는 원하는 것이 다르다 |
| `tone` | 말투 + **하지 않는 말**. "겁주지 않는다" 같은 금지도 톤이다 |
| `pillars` | **콘텐츠 기둥 3개.** 분산 금지 — 3개를 넘기면 채널 정체성이 흐려진다 |
| `forbidden` | 금칙. 알고리즘 오학습을 부르는 잡어·타깃 밖 미끼를 구체적으로 |

선택 항목(있으면 훨씬 강해진다): `lens`(모든 영상이 통과할 렌즈 한 줄) · `self_check`(그 렌즈를 통과하나 자문) ·
`story_arc` · `why` · `persona` · `signature_ip` · `hook_words` · `enemy` · `promise` · `benchmark` · `publish_cadence` · `voice`

🔴 **사용자가 말하지 않은 것을 지어내지 말 것.** 모르는 항목은 비워두고 묻는다.
6항목이 다 차기 전에는 저장하지 않는다.

### 3. 저장하고 **기계로 검사**한다

`~/.claude/zulgap/channels/<채널>.md` 에 쓴 뒤 반드시 실행:

```bash
node <이 스킬 폴더>/scripts/validate-channel.mjs "~/.claude/zulgap/channels/<채널>.md"
```

FAIL이면 **무엇이 빠졌는지 그대로 사용자에게 알리고** 2단계로 돌아가 묻는다.
임의로 채워 재시도하지 말 것 — 그게 이 검사의 존재 이유다.

### 4. 안내하고 **멈춘다**

저장 성공하면 무엇이 저장됐는지 3~5줄로 요약하고 다음을 안내한다:
*"이제 `/유튜브기획` 으로 이번 달 주제를 고를 수 있습니다."*

🔴 **다음 단계를 안내만 한다. 네가 실행하지 않는다.** 사용자가 직접 부를 때만 움직인다.

## 구간별로 타깃이 다르다

같은 채널이어도 구독 규모에 따라 **보는 사람과 원하는 것이 바뀐다.** `target`에 이걸 나눠 쓴다.

| 구간 | 누가 보나 | 원하는 것 | 채널 역할 |
|---|---|---|---|
| **0~1K** | 막막한 시작자 | 즉답·진단·안심 | 발견·각성 |
| **1K~10K** | 성장 정체 실전가 | 체계·자산화·소속감 | 신뢰 |
| **10K~100K** | 도약 권위 전문가·사장 | 도약 설계·실증·파트너 | 전환·확장 |

0~1K 구간에 거시 담론이나 책 리뷰를 넣으면 안 먹힌다. **그건 1K 이후 것이다.**

## 콘텐츠 기둥 3개 — 분산 금지

기둥은 **3개**다. 늘리면 채널이 흐려진다.

1. **교두보** — 지금 당장 검색되고 먹히는 것 (초기 주력)
2. **차별 무기** — 이 채널만 할 수 있는 것 (경쟁자가 못 따라오는 자리)
3. **확장 엔진** — 나중에 커질 것 (권위가 쌓인 뒤 시그니처)

## 고정 렌즈 (선택이지만 강력)

모든 영상이 통과해야 하는 **한 문장**을 정하면 주제 선정이 쉬워진다.
그리고 **자문 한 줄**을 붙인다 — *"이 영상은 그 렌즈를 통과하나? 답이 없으면 만들지 않는다."*

## 금칙을 구체적으로

`forbidden`은 목록만으로 부족하다. **왜 위험한지**를 붙인다.

```
❌ "자극적인 제목 금지"
✅ "'1조 부자'·'끝났다' 류 광폭 어휘 금지 — 조회수는 오르나 타깃 밖 시청자가 와서
    알고리즘이 채널을 오분류한다"
```

## 🎙 `voice` — 말투는 서술보다 **실제 발화**가 강하다

`tone`이 *"실전 사업가의 말투"* 같은 **서술**이면 대본이 흔들린다.
그 채널의 기존 영상이 있으면 **자막에서 실제 말버릇을 뽑아** `voice` 절에 넣는다.

```bash
# 자막 추출 (본인·자사 채널에 한함)
yt-dlp --write-auto-sub --sub-lang ko --skip-download -o "%(id)s" "<영상 URL>"
```

무엇을 담나 — **말버릇 어휘 3~5개** · **도입 3문장** · **클로징 시그니처 1문장** 정도면 충분하다.

🔴 **자막 원문을 통째로 붙여넣지 말 것.** 짧은 발췌만 담고, 출처(URL·업로드일)를 함께 적는다.
🔴 **오래된 영상이면 시점을 적는다** — 채널 방향이 바뀐 뒤라면 *어투는 승계하되 주제·구성은 현재 정본이 우선*이다.

### 어투에서 **채널과 무관하게 좋은 것**(누구나 써도 되는 일반 법칙)

| # | 법칙 | 왜 |
|---|---|---|
| 1 | **도입에 자기소개·로고·예고를 넣지 않는다** | 이탈이 가장 가파른 구간. 개인 기억 → 공감 질문 → 대상 연결 → 전환 질문 순이 강하다 |
| 2 | **낯선 용어는 그 자리에서 푼다** | *"잠깐, ○○란 무엇일까요"* → 바로 설명. 정보 비대칭을 남기면 이탈한다 |
| 3 | **해외 사례 → 국내 사례 2단** | *"국내 사례도 볼 필요가 있겠죠"* 로 넘어가면 시청자가 자기 일로 받아들인다 |
