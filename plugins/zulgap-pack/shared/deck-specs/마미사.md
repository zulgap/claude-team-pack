# 마미사AI — 슬라이드 제작 규격

> **이것은 채널 정본이 아니다.** 슬라이드를 그릴 때 필요한 **화면 규격과 색**만 담았다.
> 전략·타깃·톤·금칙·제목 공식은 **여기 없다** — 그건 담당자 PC의 채널 정본에만 있다.
>
> 쓰는 곳: `/유튜브대본` 의 § 발표자료 (슬라이드 덱을 만들 때)
> 대본을 쓰는 일은 이 파일로 못 한다 — 정본이 있는 사람이 한다.

## 🎨 palette — 색

`templates/deck.html` 의 `:root` 변수에 그대로 넣는다.

| 변수 | 값 | 어디에 |
|---|---|---|
| `bg` | `#09090b` | 배경 |
| `fg` | `#ffffff` | 본문 |
| `accent` | `#ec9eb4` | 강조 · 진행바 · 페이지번호 강조 |
| `dim` | `#a1a1aa` | 보조 텍스트 |
| `bad` | `#fca5a5` | 경고·부정 |
| `good` | `#a7f3d0` | 긍정 |
| `line` | `#26262b` | 구분선·테두리 |
| `card` | `#141417` | 카드 배경 |

> SSOT = 마미사 홈페이지 레포의 `tailwind.config.ts`. 어긋나면 홈페이지 쪽이 맞다.
> `line`·`card` 만 원본과 다른데, 원본이 반투명이고 **슬라이드는 겹침이 없어 불투명이 더 선명**하기 때문이다.

🔴 **다른 색을 넣지 말 것.** 2026-08-16에 브랜드 밖 색이 **133곳**까지 퍼진 뒤 사람 지적으로 발각돼
전량을 되돌렸다. 강조가 더 필요하면 새 색을 만들지 말고 `accent` 의 **굵기·크기**로 푼다.

## 📐 화면 규격 — 얼굴 PiP 가 상시 올라간다

촬영이 **화면녹화 + 우하단 얼굴 PiP** 라서, 슬라이드 하단은 영구히 못 쓴다.

| 항목 | 값 | 왜 |
|---|---|---|
| 무대 | `1920 × 1080` | 창 크기에 맞춰 통째로 축소(scale) |
| PiP 크기 | `440 × 248` | 표정이 읽히는 최소치. 더 작으면 있으나 마나, 더 크면 슬라이드를 먹는다 |
| PiP 위치 | 우하단 · 우측·하단 마진 각 `48px` | 시선이 좌→우로 흐르고, 본문이 좌측 정렬이라 좌하단은 더 가린다 |
| 🔴 **세이프존** | **하단 `360px`** 에 핵심 내용 금지 | PiP 248 + 마진 48 + 여유 64 |
| 페이지번호 `#idx` | **좌**하단 (`left:44px`) | 우하단은 PiP와 정면 충돌 |
| 진행바 `#bar` | 하단 전폭 · 높이 `8px` | PiP가 위에 얹혀도 무해 |

### 검사는 눈이 아니라 렌더로

```bash
node <jedi-youtube-script 스킬 폴더>/scripts/check-safezone.js <슬라이드.html> --safe 360
```

**기대: 침범 0장 · 상단 잘림 0장.** 걸리면 그 장의 폰트를 줄여 맞추고 **다시 잰다.**

🔑 2026-08-16 실측에서 68장 중 **6장이 50px 씩 침범**해 있었고, 전부 눈으로는 멀쩡해 보였다.

### 🔴 줄이지 말 것 (렌더 실측으로 맞춘 값)

- 터미널 블록 `.term` 폰트 `25px` / 행간 `1.45`
- 도식 `max-height 520px` (= 1080 − 상단 96 − 세이프존 360 − 여유)

키우면 다시 얼굴에 가려진다.

## ⚠️ 아직 굳지 않은 값

아래는 **렌더로만** 확인됐고 실촬영 전이다. 첫 촬영 뒤 재산정한다.

| 항목 | 지금 | 재산정 조건 |
|---|---|---|
| PiP 크기 | `440×248` | 표정이 읽히나 / 슬라이드를 먹지 않나 |
| 애니메이션 지연 | `0.24~0.90s` | 낭독 속도와 맞나 |
| 장당 분량 | 11분에 33장 (≈20초/장) | 실제 낭독 시간과 대조 |
