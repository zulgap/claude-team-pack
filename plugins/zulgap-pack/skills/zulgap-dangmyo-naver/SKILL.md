## 개요

댕묘는 홈페이지(`dangmyo.com`)와 네이버 블로그 두 채널을 쓴다.
홈페이지 글이 발행되면 같은 주제를 네이버에도 올리는데, **본문을 그대로 복사하면 안 된다.**
중복 콘텐츠가 되면 구글 원본성 평가에서 자체 도메인이 손해를 본다(발행 배선 저널, 「같은 데이터 재가공 → 네이버 발행 — 보류」).

이 스킬은 그 재가공을 규칙대로 수행하고, 붙여넣기만 하면 되는 상태의 노션 카드를 만든다.
**발행은 하지 않는다.** 네이버는 자동 발행 배선이 없고, 사람이 노션에서 복사해 직접 올린다.

## 언제 쓰나

```
"/zulgap-dangmyo-naver"
"댕묘 네이버 재가공해줘"
"홈페이지에 올라간 글 네이버에도 올리게 카드 만들어줘"
"댕묘 8월 발행분 네이버용으로 만들어줘"
```

대상을 지정하지 않으면 아직 네이버 카드가 없는 홈페이지 발행글을 **전부** 찾아 한 번에 처리한다.

## 안 되는 경우

- **새 글을 쓰는 작업** → 블로그 작성 스킬이 할 일이다. 이 스킬은 이미 발행된 글만 다룬다
- **홈페이지에 아직 발행되지 않은 글** → 원문 URL이 있어야 본문에 넣을 수 있다. 「11. 발행완료」가 아니면 건너뛴다
- **네이버에 실제로 올리는 것** → 사람이 한다. 이 스킬은 카드까지만
- **댕묘 외 브랜드** → 편집 기준·카테고리·도메인이 전부 다르다

| 속성명 | 타입 | 용도 |

🔴 **「월」·「연」은 카드 생성 도구가 채워 주지 않는다.** 별도로 넣지 않으면 무조건 빈칸으로 남고 월별 뷰에서 빠진다. 옛 `8월`·`8월 기획안` 계열 선택지가 섞여 있으므로 감으로 고르지 말 것.

**네이버 채널**

- 계정 ID는 `cmorec`, 공개 블로그 주소는 `blog.naver.com/dangmyo-`(끝의 하이픈까지가 주소다). 둘을 혼동하지 말 것
- 카테고리 9개 — `댕 · 강아지`(사료·급여 / 산책·목욕 / 처음 키울 때) · `묘 · 고양이`(모래·화장실 / 사료·급여 / 처음 키울 때) · `성분·가격 비교` · `댕묘 소개` · `보관함`(비공개)
- `성분·가격 비교`는 **제품의 성분·단가를 비교하는 글** 자리다. 관리·처리형 글(버리기·급여량)은 축종별 소분류로 간다

**댕묘 편집 기준** — 출처 없는 문장을 쓰지 않는다. 브랜드·업체를 지목하지 않는다. 수의학적 판단은 다루지 않고 "이런 신호면 병원"까지만 쓴다.

## 동작 방식

### STEP 1 — 대상 찾기

노션 MCP의 SQL 모드로 조회한다. 아직 네이버 카드가 없는 홈페이지 발행글이 대상이다.

```sql
SELECT url, "기획안(👇클릭해주세요)" AS title, "발행 링크", "키워드", "주제",
       "date:실 발행일:start" AS pub
FROM "collection://7f410191-5034-4dae-8648-7e109bfffe27"
WHERE "동료사명" = '댕묘'
  AND "콘텐츠 구분" = '홈페이지 블로그'
  AND "단계" = '11. 발행완료'
```

같은 조건에서 `콘텐츠 구분 = '네이버블로그'` 카드도 함께 뽑아 **주제가 겹치는 것은 제외한다.**
중복 카드를 만들면 같은 글이 두 번 발행된다.

대상이 0건이면 "대상 없음"으로 보고하고 끝낸다. 단계가 7에 머문 글을 대신 끌어오지 않는다
(도구가 갈 수 있는 끝이 7이고 11은 사람이 바꾸는 칸이라, 7은 "아직 사람이 확인 안 함"을 뜻한다).

### STEP 2 — 원문 읽기

각 카드의 본문 전체를 읽는다. 문장·수치·출처·이미지 URL·캡션을 모두 확보한다.
**이미지는 마크다운 URL을 그대로 복사해 쓴다** — 다시 생성하지 않는다.

### STEP 3 — 재가공 (본체)

🔴 **복사 금지.** 아래를 전부 적용한다.

**하드리밋 (수치)**

| 항목 | 값 |
|---|---|
| 표의 열 수 | **최대 3열** — 네이버 모바일에서 4열 이상은 잘린다 |
| 해시태그 | **정확히 10개** |
| 썸네일 | 1080 x 1080, 제목 **최대 4줄** |
| FAQ | 3~4건 (원문보다 줄인다 — 본문과 중복되는 항목을 뺀다) |

**금지 리터럴 — 아래가 결과물에 하나라도 있으면 실패다**

- 원문 문장을 그대로 옮긴 문단 (수치·법조문·인용문은 예외 — 바꾸면 거짓이 된다)
- 마크다운 링크 `[텍스트](주소)` — 네이버 붙여넣기에서 깨진다. `기관명 — 주소` 텍스트로 바꾼다
- 특정 브랜드·제품명, 그리고 그것을 암시하는 별칭
- 출처가 없는 새 문장

**해야 할 것**

1. **문장을 다시 쓴다.** 사실·수치·출처는 원문과 동일하게 유지한다
2. **구성을 네이버 검색 의도에 맞춰 재배치한다.** 검색어가 묻는 답(결론 표·핵심 목록)을 앞으로 당긴다
3. **표를 3열 이하로 줄인다.** 빠진 열은 본문 문장으로 흡수하고, 전체 표는 홈페이지 원문으로 넘긴다
4. **홈페이지 이미지를 전부 넣는다.** 절대 순서가 아니라 **그 이미지가 설명하는 내용 옆**에 붙인다. 구성을 바꿨으면 이미지도 따라 움직인다. 캡션은 원문 그대로
5. **본문 말미에 홈페이지 원문 URL과 `dangmyo.com`을 넣는다.** 자체 도메인으로 넘기는 통로이자 어느 쪽이 원본인지 알리는 신호다
6. **해시태그 10개.** 앞 3~4개는 카드의 「키워드」 속성값과 같게 맞춘다(순위체크가 읽는 값과 어긋나지 않게). 뒤쪽은 붙여쓰기 롱테일·제도 키워드. `#댕묘`는 전 글 공통

**셀프체크 — 카드를 만들기 전에 스스로 확인한다**

- [ ] 원문과 나란히 놓았을 때 같은 문단이 하나도 없나
- [ ] 표 중 4열 이상이 하나도 없나
- [ ] 마크다운 링크가 본문에 0개인가
- [ ] 원문 이미지 개수와 새 본문 이미지 개수가 같은가
- [ ] 해시태그가 정확히 10개이고 브랜드·제품명이 없나

### STEP 4 — 예상 발행일

🔴 **예상 발행일 = 홈페이지 실 발행일 + 1일.**
따라서 **홈페이지에 같은 날 나간 글들은 네이버에서도 같은 날로 묶인다.** 균등 간격으로 흩지 않는다.

- **월요일 발행 가능** — 이 스킬은 네이버블로그 월요일 제외 규칙을 쓰지 않는다
- **토·일·공휴일은 제외** — 걸리면 다음 평일로 민다. 같은 날로 묶인 글은 함께 민다
- 공휴일은 매번 조회해 판정한다. 대체공휴일이 있으므로 목록을 코드에 박지 않는다. 애매하면 사용자에게 확인한다
- 계산한 날이 **이미 지났거나 오늘이면** 가장 가까운 발행 가능일로 당겨 올리되, 홈페이지 발행 순서를 뒤집지 않는다. 자리가 모자라면 그 주에 한해 토·일도 쓸 수 있다

### STEP 5 — 썸네일

`scripts/make_thumbnail.py` 로 만든다. 배경·서체·색·레이아웃은 고정이고 **바뀌는 것은 제목뿐**이다.

```bash
python scripts/make_thumbnail.py --title "고양이 모래|종량제 봉투에|버리면 안 됩니다" --out thumb.png
```

- 카드 제목을 그대로 넣지 말고 **4줄 이내로 압축**한다. 검색 키워드를 첫 줄에 둔다
- 줄바꿈은 `|` 로 직접 지정한다. 자동 분할은 의미 단위를 못 지킨다
- 배경·폰트는 첫 실행 때 자동으로 내려받아 캐시한다. 저장소에 넣지 않는다
- 🔴 **한글을 이미지 생성 모델에 그리게 하지 말 것.** 오탈자가 나고 재시도 비용이 크다. 이 스크립트는 글자를 직접 그린다

### STEP 6 — 카드 만들기

콘텐츠마스터에 새 카드를 만든다. 원본 카드는 건드리지 않는다.

- `동료사명` = `댕묘` / `콘텐츠 구분` = `네이버블로그` / `단계` = `5. 초안작성완료`
- `월`·`연`을 **직접 채운다**(형식 `26년 8월` · `2026년`)
- `참고링크`에 홈페이지 원문 URL, `특이사항`에 재가공 메모와 배정한 네이버 카테고리

카드 본문 구성:

```
> 붙여넣기 안내 — 카테고리, 소제목 재지정, 링크 걸기
---
## 본문
(재가공 본문 + 홈페이지 이미지 + 원문 링크 + dangmyo.com)
해시태그 10개
썸네일 (1080 x 1080)
---
## 재가공 내역 (홈페이지 원문과 달라진 것)
## 발행 전 체크
```

썸네일은 노션에 **파일로 업로드**해 카드 안에서 바로 보이게 한다(file upload → `markdown_source`).
네이버는 외부 이미지 URL을 막으므로, 카드의 이미지는 붙여넣기용이 아니라 **내려받기용**이다.
「발행 전 체크」에 "이미지를 내려받아 네이버 에디터에 직접 업로드"를 반드시 적는다.

### STEP 7 — 보고

만든 카드 목록·예상 발행일·배정 카테고리를 표로 보고한다.
카테고리 배정은 제안이므로 사용자가 바꿀 수 있다고 함께 알린다.

## 실측 결과 (2026-08-05)

홈페이지 발행글 4편(고양이 모래 배출 / 강아지 사료 급여량 / 고양이 사료 표시사항 / 강아지 사료 등급표)을
네이버 카드 4장으로 재가공하고, 기존 소개글 카드까지 5장에 썸네일을 넣었다.

- 표 축약 실측: 급여량 글 14행 6열 → 8행 3열, 모래 글 5열 → 2~3열
- 홈페이지 이미지 7장을 동일 맥락 위치로 이식(2 / 1 / 3 / 1장)
- 예상 발행일: 홈페이지 8/3분 → 8/5, 8/4분 3편 → 8/6 (같은 날 묶음 규칙 적용)
- 썸네일 5장 생성, 오탈자 0. 한글 11,172자 커버 확인
