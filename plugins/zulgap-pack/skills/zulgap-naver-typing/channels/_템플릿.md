# <채널 이름> — 네이버 타이핑 설정

> 이 파일을 복사해 `<동료사명>.md` 로 만들고 아래 4개를 채운다.
> **파일 한 벌 = 동료사 하나.** 노션 조회가 「동료사명」으로 돌기 때문이다.

| 항목 | 값 | 설명 |
|---|---|---|
| 프로필키 | `` | 크롬 프로필 폴더 이름. 영문 소문자·숫자·하이픈만 (예: `ff1030`) |
| 블로그ID | `` | `blog.naver.com/` 뒤에 오는 부분 |
| 동료사명 | `` | 노션 「동료사명」 값과 **정확히 같아야** 조회된다 |
| 카테고리번호 | `` | 스킬이 **이 번호로 찾는다**. 아래에서 얻는 법 참고 |
| 카테고리 | `` | 번호가 맞는지 **대조**하는 이름 |

## 🔴 번호와 이름을 «둘 다» 적는다

스킬은 **번호로 찾고, 이름으로 확인한다.** 한쪽만으로는 고르지 않는다.

- **번호만 보면**: 그 자리에 사람이 다른 카테고리를 만들어 뒀을 때 못 알아챈다
- **이름만 보면**: 같은 이름이 둘일 때 어느 쪽인지 모른다

둘이 어긋나면 스킬은 **멈추고** 「번호 ○○의 이름이 △△ 입니다」라고 알려 준다.
네이버에서 이름을 바꾸셨다면 그때 이 파일도 같이 고치면 된다.
비슷한 걸 골라 «남의 카테고리에 글을 올리는» 것보다 멈추는 편이 낫다.

### 카테고리 번호 얻는 법

블로그에서 그 카테고리를 눌렀을 때 주소창의 `categoryNo=` 뒤 숫자다.

```
https://blog.naver.com/ff1030?categoryNo=112   ← 112
```

이름은 네이버 「관리 → 메뉴·글·동영상 관리 → 블로그」 에 보이는 것을 **복사해서** 붙여넣는다.
하위 카테고리도 자기 이름만 적으면 된다 (`마케팅 줄GAP`) —
목록에 붙는 `하위 카테고리 ` 접두사는 스킬이 알아서 뗀다.

## 🔑 여러 동료사가 한 계정을 쓸 수 있다

프로필키·블로그ID가 **다른 파일과 같아도 된다.** 실제로 마미사·줄갭·RPG는 `ff1030` 한 계정을
같이 쓰고 **카테고리로만 갈린다.** 그때 크롬 창은 계정당 하나만 열린다(프로필 락) — 그게 맞다.
같은 계정을 두 창으로 열면 로그인이 서로 밀어낸다.

## 처음 한 번

```bash
node scripts/chrome-session.js open <프로필키> "https://blog.naver.com/<블로그ID>?Redirect=Write"
```

뜬 창에서 이 계정으로 **네이버 로그인**.

🔴 **「로그인 상태 유지」를 반드시 켤 것.** 안 켜면 창을 닫는 순간 로그아웃된다.
같은 프로필키를 쓰는 다른 동료사가 이미 로그인해 뒀다면 **다시 할 필요 없다.**
