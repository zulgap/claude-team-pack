# <채널 이름> — 네이버 타이핑 설정

> 이 파일을 복사해 `<채널키>.md` 로 만들고 아래 3개를 채운다.
> 채널마다 네이버 계정이 다르므로 **채널마다 한 벌씩** 필요하다.

| 항목 | 값 | 설명 |
|---|---|---|
| 프로필키 | `` | 크롬 프로필 폴더 이름. 영문 소문자·숫자·하이픈만 (예: `abc`) |
| 블로그ID | `` | `blog.naver.com/` 뒤에 오는 부분 |
| 동료사명 | `` | 노션 「동료사명」 값과 **정확히 같아야** 조회된다 |

## 처음 한 번

```bash
node scripts/chrome-session.js open <프로필키> "https://blog.naver.com/<블로그ID>?Redirect=Write"
```

뜬 창에서 이 채널 계정으로 **네이버 로그인**. 그 뒤로는 유지된다.
