## 0. 여정 — 다섯 자리는 목적이 각각 다르다

> 출처: 3기(2) 「제목>후킹>서론>본론>결론」

| 자리 | 목적 (원문 그대로) |
|---|---|
| **제목** | 많은 글들 중 **선택을 받게** 하자 |
| **후킹** | **다음 문장까지** 보게 하자 |
| **서론** | **본론으로 넘어가게** 하자 |
| **본론** | **끝까지** 보게 하자 |
| **결론** | 핵심을 찔러 **행동을 유도**하자 |

**한 자리가 실패하면 뒤는 없다.** 제목이 안 먹히면 후킹을 읽을 사람이 없고, 후킹이 안 먹히면 서론이 없다.

**일반 블로그에 없는 것 = 프리퀀시 · 개요 · 퍼널** (3기(1) 원문. 3기(2)는 「프리퀀시·퍼널」 2가지로 적어 문서 안에서도 갈린다)

## 1. 프리퀀시 — 키워드 온도

> 출처: 2기 · 3기(1) · 3기(2) 공통 / 개요 칸 라벨은 「마케팅 글쓰기 끝내"줄갭"」

### 목적 (원문)

> 독자의 상황과 감정, 원하는 것을 파악하기 위함입니다.
> **프리퀀시를 제대로 파악하여 글을 쓴다면, 독자는 "본인을 위한 글이구나" 라고 느끼게 됩니다.**

### 온도 4단계 — 같은 병인데 검색어가 다르다

| 온도 | 키워드 예시 | 그 사람의 속마음 (원문) |
|---|---|---|
| **25도** | 자고 일어나니 어지러움 | "왜 이렇게 어지럽지? 나 무슨 병 걸렸나?" — **증상만 안다** |
| **50도** | 이석증 | "이석증이 달팽이관에 돌이 빠져나온 거라고? 그럼 어떻게 치료받아야 하지?" — **병명을 알았다** |
| **75도** | 이석증 치료 | "신경과를 가면 치료할 수 있다고? 주변에 신경과 어디 있지?" — **해결책을 찾는다** |
| **99도** | (지역명) 신경과 | "오 여기서 이석증 치료 많이 했네. 후기도 괜찮은데 여기 가볼까?" — **업체를 고른다** |

**방향 규칙**: 메인 키워드 → 세부 키워드로 갈수록 **구매 확률이 올라간다**(온도가 높아진다).

⚠️ 「마케팅 글쓰기 끝내"줄갭"」 판본은 99도가 아니라 **100도**로 적고 `(0도)`도 한 번 쓴다. 4단계라는 것은 같다.

### 두 종류의 프리퀀시 — 개요 1·2번 칸이 이것이다

| 개요 칸 | 원문 라벨 | 예시 (상간소송 글) |
|---|---|---|
| 나는 누구인가 | **동료사 프리퀀시** | "상간죄 피고 전문 변호사" |
| 글을 읽을 타겟은 누구인가 | **컨슈머 프리퀀시** | "상간녀로 고소당한 2,30대 여성 / 고소취하를 하고 싶은 사람" |

### 속마음을 어떻게 알아내나 (원문 2단계)

1. **지식iN · 유튜브 댓글**을 본다 — 독자가 어떤 키워드를 검색하는지 + **현재 상황과 문제점**까지 파악되므로 매우 중요한 작업
2. **엉덩이로 찾는다** — *"내가 독자라면 어떤 걸 검색할까?"* 를 머릿속으로 **롤플레잉**한다. 즉 **고객의 세계관에 들어간다**

> 키워드란? **고객의 마음.** 단순히 내가 넣고 싶은 키워드를 넣는 것이 아니다.

**도구 연결**: `ext_golden_keyword({ mode: 'question' })` 가 지식iN 질문을 그대로 가져온다 — 위 1번을 도구가 대신한다. **지어낸 속마음 대신 실제 질문을 근거로 쓴다.**

### 어느 채널로 재나 (`resolveFrequencyLocale` — 값 SSOT)

| 채널 · 언어 | locale | 이유 |
|---|---|---|
| 네이버 블로그 | `ko` | 네이버는 정의상 한국어 |
| 홈페이지 + 국문 | `google` | 홈페이지 SEO의 주 채널은 구글 |
| 홈페이지 + 영문 | `en` | 구글 US/English (정코리아) |

🔴 **채널이 1차 축이고 언어는 구글 축 안에서 갈린다.** 네이버는 한국어만, 구글은 한국어·영어 둘 다 잰다 — 채널과 언어를 1:1로 묶으면 칸이 하나 사라진다.
🔴 **홈페이지 글을 네이버 발행량으로 재면 판정이 뒤집힌다** — 실측: `재혼`이 네이버 포화(2,570·100+)인데 구글 한국은 40,500·LOW(13).

### 독자 프로파일 (`READER_PROFILE`)

성별 `남성 / 여성 / 무관` · 연령 `20~30대 / 40~50대 / 무관`

## 3. 갭언어 9종 — 제목·후킹·소제목을 만드는 엔진

> 출처: 노션 「🤩 갭언어 "줄갭"」 (블로그 강의가 아니라 **별도 문서**)
> 🔴 **원문은 각 유형에 「한 줄 정의」를 붙이지 않았다.** 명칭 + 예시 문구가 전부이고, 괄호 안 별명이 정의를 대신한다. **아래 설명은 원문 예시에서 읽히는 것만 적었고 지어내지 않았다.**

**쓰는 자리 3곳** (원문 절 제목 그대로)
- **제목** — *"선택받지 못하면 아무 의미 없다."*
- **첫줄(후킹문구)** — *"시선을 잡지 못하면 의미가 없다."*
- **소제목** — *"알 만한 내용이면 나간다."*

| # | 갭언어 | 별명 | 원문 예시 |
|---|---|---|---|
| 1 | **통념깨기** | 의외성 | "저렴한데도 품질이 좋은 이유" / "문의주지마세요" / "줄갭은 마케팅회사가 아닙니다." / "저는 마케터가 아닙니다. 마케팅에 미친 사업가입니다." |
| 2 | **손실회피** | 두려움 자극 | "후회합니다." / "망합니다." / "무조건~~ 합니다." |
| 3 | **사회적증거** | 뭐야 나만 몰랐어? | "아직도? / 여전히?" / "의외로 모르는" / "나만 모르는" / "이거 이해하면 성공한 사람입니다." / "논란중인" |
| 4 | **구체성N가지** | — | "성공하는 N가지 방법" / "실패원인 TOP3" / "마케팅 잘하는 3가지 방법" |
| 5 | **신뢰성** | — | "N년차 변호사가 말해주는" / "사업만 5가지 해본 대표가 알려주는" / "이혼변호사가 말하는 바람 많이 피우는 직업 TOP3" |
| 6 | **공감형** | — | "~~하신 분들만 보세요" / "한다면 보세요" / "오직 이런분들만 보세요" |
| 7 | **끝장** | — | "A부터 Z까지" / "한방에 끝내드림" / "종결" |
| 8 | **이유방법비법** | 이유/방법/비법/비밀 | "1급 비밀" / "특급비밀" / "해야만 하는 이유" / "단 한가지 이유" |
| 9 | **이것저것** | — | "000몰라 망합니다." / "'이것'몰라 망합니다." / "'이것만 알면 끝" / "결국 '이것'때문입니다." |

**상위 개념 — 갭언어의 핵심요소 6가지 (by 스틱)**: 단순성 · 의외성 · 구체성 · 신뢰성 · 감성 · 스토리

## 4. 글 유형(서론) 3종

> 출처: 2기 「서론의 종류 3가지」 + 3기(2) 「서론에 나와야 할 것」
> ⚠️ **3기는 2개로 축약**(문제해결형·통념깨기형)했고 `가치입증형`을 뺐다. **사유는 원문에 없다.** 2기·「마케팅 글쓰기」 두 문서가 3개를 쓰고 코드 SSOT도 3개이므로 **3개를 정본으로 둔다.**

| 유형 | 언제 (원문) | 서론에 나와야 할 것 |
|---|---|---|
| **문제해결형** | 이미 독자가 **문제를 아는** 경우 | 문제 공감 → 문제 언급 → **해결해주겠다**는 내용 |
| **통념깨기형** | 독자가 **문제가 뭔지도 모르는** 경우 | 기존 통념과 **반대되는 내용** → 왜 다른 얘기를 하는지 **설명해주겠다**는 내용 |
| **가치입증형** | 가치입증 | **결과만 먼저** 보여준 후 궁금증을 유발 |

**서론의 목적**: 기존의 통념에 「갭」을 만들어 **본론으로 넘어가게** 하자.

## 5. 본론 — 유형 3종 · 주이사강 · 퍼널

> 출처: 2기 「본론의 종류」·「주이사강」 / 배치 예시는 3기(2) 문제해결형 개요

### 5-1. 본론 유형 3종 — 언제 쓰나 + 구조

`BODY_TYPE_SPEC` (값 SSOT)

| 유형 | **언제 쓰나** | **구조** |
|---|---|---|
| **솔루션형** | 줄 수 있는 **솔루션이 충분**할 때 | 서론=문제제기 → 본론1·2·3=**전부 솔루션** → 결론=실질주제+행동유도 |
| **통념깨기형** | 줄 수 있는 **솔루션이 부족**할 때 | 서론=통념깨기 → 소제목1·2=**통념깨기** → 소제목3=솔루션 → 결론 |
| **개념설명형** | 남들이 **개념만 설명하는 시장**에서 차별화 | 서론=통념깨기 → 소제목1=**개념** → 소제목2=**통념깨기** → 소제목3=솔루션 |

🔴 **이 「언제 쓰나」가 없으면 유형 선택이 감으로 흐른다.** 코드 주석이 *"이 조건이 없으면 LLM이 늘 솔루션형만 고른다"*고 경고한 자리다.

원문 근거:
> **솔루션형의 뜻** — "소제목 1,2,3을 모두 문제에 대한 솔루션으로 채우는 본론 유형". 솔루션형에는 **솔루션으로 내용이 충분하기 때문에** 본론에서 우리의 실질적 주제가 드러나지 않습니다.
> **개념설명형 효과** — 다른 블로그는 모두 개념만 설명해 줍니다. 그런 시장에서 우리는 경각심과 문제해결을 통해 **전환까지 이어질 수 있는 경쟁력**을 얻습니다.

⚠️ **실측 (2026-08-18 RPG 38편)**: 개념설명형 57.9% · 통념깨기형 28.9% · 솔루션형 10.5% · 무유형 2.6%.
편중이 **개념설명형 쪽**이다. 「언제 쓰나」로 골랐는지 매번 확인할 것.

### 5-2. 주이사강 — 본론 하나의 내부 구조

원문 예시 (2기):
> **주** : 카페인은 일을 하는데 오히려 안좋다.
> **이** : **왜냐하면** 카페인은 일시적인 각성제고, 중독되기 때문이다.
> **사** : **실제로** 커피를 계속 마시면, 커피 없이는 일의 능률이 떨어진다는 연구 결과가 있다.
> **강** : **따라서**, 일의 능률을 높이려면 커피를 조금씩 줄이는 것이 좋다.

= **주장 → 이유("왜냐하면") → 사례("실제로") → 강조("따라서")**. 네 줄이 한 덩어리다.

### 5-3. 본론 한 개의 배치 — 퍼널글은 「강」 다음

원문 예시 (3기(2)):
```
본론1
  * 소제목 : 청소 전문 업체가 제일 신경쓴다는 줄눈 시공
  - 주 : 화장실 타일에 줄눈 시공을 해야한다.
  - 이 : 줄눈만 하얘져도 훨씬 깨끗해 보이기 때문
  - 사 : 실제로 청소업체들은 화장실 청소할 때 줄눈을 제일 신경쓴다.
  - 강 : 그러니 호텔식 화장실처럼 깨끗해지려면 줄눈시공부터 해라.
  퍼널글 : [줄눈 타일 시공하는 방법]          ← 다른 글로 가는 링크
  "또 어떻게 해야 깨끗해 보일까요?"            ← 다음 본론으로 넘기는 질문 (정식 명칭 "인용구")
```

- **퍼널글은 「강」 바로 다음, 인용구 바로 앞**
- **마지막 본론에는 퍼널글도 인용구도 붙지 않는다** (원문 본론3이 그렇다)
- 통념깨기형 본론1은 **퍼널글 없이 인용구만** 오기도 한다

**퍼널글 = 내부 링크.** SKILL.md STEP 3의 「내부 링크 2~3개」가 이것이며, 실무 규칙(발행완료 글만·앵커는 제목·문단 안)은 거기에 있다.

### 5-4. 본론에 들어가야 하는 핵심요소 5가지 (원문)

1. **3개 이상의 문단(소제목)**으로 구성한다
2. **두괄식**으로 쓴다
3. 문단이 길어지면 **현재 무슨 주제를 다루고 있는지** 언급한다
4. **독자의 세계관으로 들어가, 발생하는 갭(의심)을 줄인다**
5. 본론이 너무 길면 **끝까지 볼 수 있는 장치**를 심는다 → 자기인식

## 6. 결론 — 핵심요약 + 행동유도

> 출처: 2기·3기 공통 / `시리즈형`만 「마케팅 글쓰기 끝내"줄갭"」

**형식**: ① **핵심요약** — 어려운 내용을 한 번 요약하여 상기시킨다 → ② **행동유도** — 우리가 원하는 행동을 하도록 액션을 시킨다

### 행동유도 8종 (`CTA_TYPE`)

| 유형 | 원문 예시 |
|---|---|
| **사회적증거** | "많은 분들께서 문의를 주고 계십니다." / "현재 문의가 많아 대기가 될 수 있음을 알려드립니다." |
| **희소성** | "딱 3분만 모십니다" / "제한된 인원만 다룰 수밖에 없어 많이 못 받는 점 죄송합니다" |
| **통념깨기** | "저를 무조건 이용하라고 드리는 말씀은 아닙니다" / "그냥 한번 해볼까 하는 분들은 지원하지 말아주세요. 누군가는 인생이 바뀔 수도 있습니다." |
| **행동촉구형** | "누군가에겐 인생을 바꿀 기회일지도 모릅니다. 지금 바로 지원하세요" |
| **영감형** | "단순히 마케팅 대행을 맡기시겠습니까? / 온라인 진출과 독립을 돕는 회사와 함께하시겠습니까?" |
| **허들낮추기형** | "치킨 두 마리도 안 되는 가격으로 문의하세요" / "수임이 아닌 간단한 상담이라도 꼭 받으셔야 합니다." |
| **두려움자극형** | "직장을 잃기 싫다면, 꼭 대비해 놓으세요" / "지금 선택이, 평생 전과를 달고 사냐 마냐를 결정짓습니다" |
| **시리즈형** | 내용이 길거나 다른 글로 이어지는 게 좋다고 판단될 때 다음 글로 유도. **단순 "다음 콘텐츠에서 이어집니다"가 아니라** 다음 콘텐츠에서 다룰 이야기를 **서론처럼 흥미를 유발하고 끝낸다**(Unfinished) |

### 사람이 행동하기 위한 5가지 장치 (원문 대전제)

> 자신의 꿈을 독려하고 / 실패를 옹호하고 / 두려움을 잠재우고 / 의심에 동조하고 / **적에게 함께 돌을 던지는** 사람.

## 7. 리뷰 3회 8문항

> 출처: 2기·3기(1)·3기(2) **세 벌 전부 동일** / `buildReviewRounds` (값 SSOT)
> ⚠️ 3기(2)만 명칭이 「회고」다. 내용은 같다.

**초안은 쓰레기다** — 빠르게 쓰고 세 번 본다.

| 회차 | 무엇을 보나 | 문항 |
|---|---|---|
| **1회 — 주제** | 글 전체의 **논리**가 명확한지 | ① 서·본·결이 목적에 부합하는가 ② 표면적 주제가 일관되는가 ③ **실질적 주제를 너무 빨리 보여주진 않았나** ④ 소주제당 주제가 1개로 명확한가 |
| **2회 — 문장** | **문장의 논리**가 명확한지 | ① **주이사강이 틀어지지 않았나** ② 더 추가할 예시·사례는 없나 |
| **3회 — 형식** | 오탈자·키워드 | ① 오타는 없나 ② **키워드를 4~6회 넣었나** |

🔴 **키워드 횟수는 원문이 6~7회, 현행 정본은 4~6회다** — 2026-07-29 사장님 확정으로 양 채널을 4~6으로 통일했다(구 3~5 / 6~7 드리프트 소거). **원문을 보고 6~7로 되돌리지 말 것.**
⚠️ 문항 수는 **8이다.** 7/29 설계서가 "9문항"이라 적었으나 원문 세 벌을 세면 4+2+2=8이다. 코드가 옳다.
