## 개요

노션 데이터베이스의 콘텐츠들을 월별로 스케줄링할 때 사용합니다. 반복적인 날짜 계산과 공휴일 처리, 노션 업데이트를 자동화합니다.

## 언제 쓰나

- 클라이언트명 + 월 + 콘텐츠 구분(네이버블로그·홈페이지블로그·카드뉴스·유튜브 숏폼 등)을 주고 "예상 발행일을 정해달라"고 할 때
- 이미 있는 콘텐츠 카드들에 발행일만 채우면 되는 경우 (콘텐츠 자체를 새로 기획하는 건 아님)

## 안 되는 경우

- 노션에 카드가 아직 없다 → 카드 생성은 이 스킬의 범위 밖. 먼저 카드를 만들고 이 스킬을 부른다.
- "실 발행일부터 시작해달라" 같은 표준 규칙(요청일 다음날 시작)과 다른 커스텀 시작일을 원할 때 → 그 요청대로 시작일만 바꿔서 진행하되, 표준 규칙과 다르다는 점을 사용자에게 확인받는다(실제로 이런 커스텀 요청이 있었음, 2026-08-02).

## 사용 방법

### 기본 사용
```
"엔노블 26년 7월 네이버블로그, 홈페이지블로그 예상 발행일 스케줄링해주세요"
"검단가온치과 26년 8월 블로그 콘텐츠 스케줄링"
"26년 9월 카드뉴스 발행일 정해주세요"
```

### 공휴일 지정
```
"7월 스케줄링인데, 제헌절(7/17) 말고 추석(9/18~20)도 제외해줘"
```

- 월과 콘텐츠 구분으로 사전 필터링된 뷰 URL을 받거나, 데이터소스 `collection://7f410191-5034-4dae-8648-7e109bfffe27`("콘텐츠마스터 관리 메인 DB")를 직접 조회
- ⚠️ 이름이 비슷한 "콘텐츠마스터 관리 메인 DB (TEST)"(`collection://2b1efa2f-2c3b-818a-ac72-000b2b675ad2`)는 별개의 구식 DB — 실제 운영 데이터가 없을 수 있으니 혼동하지 말 것 (2026-08-02 실측 혼선 있었음)
- 사용하는 속성: "월", "콘텐츠 구분"(필터), "예상 발행일"(쓰기 대상), 제목(에피소드 번호 감지용), "단계"(선택, 값이 "8.타이핑 요청"이면 최우선 배치 — ⭐ v1.5)

## 스킬의 동작 방식

### 1단계: 노션 뷰 확인
- 제공된 노션 뷰 URL을 열거나 데이터소스를 직접 조회해 "월"과 "콘텐츠 구분" 필드 값으로 대상 항목을 추출

### 2단계: 날짜 범위 결정 (⭐ 중요)
**시작일: 요청일 기준 다음날 (표준 규칙)**
- 예: 오늘(요청일)이 7월 6일이면 → 7월 7일부터 시작
- 예: 오늘이 7월 31일이면 → 8월 1일부터 시작 (월 경계 자동 처리)

**종료일: 요청한 월의 마지막 날**

### 3단계: 평일 추출 및 공휴일 제외 — 🔴 계산은 스크립트가 한다 (⭐ v1.6)

**2~6단계의 날짜 계산 전부를 `scripts/schedule.py` 가 한다. AI가 머릿속으로 세지 않는다.**
근거: 범용 블로그 스킬의 실사고 — *"직접 세면 틀린다(키워드 5회라 보고했으나 실제 12회)"*.
배치 건수가 늘수록 하루씩 밀리는 오류는 사람이 못 잡는다.

```bash
# 1) 노션에서 뽑은 항목으로 input.json 작성 (형식: scripts/schedule.example.json)
python scripts/schedule.py input.json          # 결과 JSON → 사용자에게 드라이런으로 제시
```

스크립트가 처리하는 것: 평일 추출(토/일 제외) · 한국 공휴일 제외 · 추가 제외일 ·
네이버 월요일 제외(v1.4) · 우선순위(v1.5) · 에피소드 정렬 · 균등 배치 · 멀티채널 +1 영업일 ·
간격 2~7일 이탈과 월 경계 초과는 **경고로 반환**(사람이 판단).

- **공휴일 데이터 SSOT**: 스크립트 안 `KR_HOLIDAYS` 상수 — 원천은 judgmentos
  `unified-agent/shared/kr-holidays.js`(2026-07-30 두 소스 교차 확인분). 그쪽이 갱신되면 함께 갱신.
- ⚠️ **제헌절(7/17)은 2026년부터 공휴일로 재지정**됐다(국회 통과·공포 3개월 후 시행). 교차 확인된
  수집 데이터에 근거한다. 🔴 실사고(2026-08-03): "2008년에 빠졌으니 공휴일 아님"으로 이 문서를
  잘못 "정정"했다가 수집 SSOT 대조로 되돌렸다 — **공휴일 판단은 일반 상식이 아니라 수집 테이블로.**
- 데이터 없는 연도(2027~)는 주말만 제외하고 `holiday_data_missing: true` 를 반환한다 —
  이 플래그가 뜨면 **관보 확정본으로 테이블을 채운 뒤** 재실행 (조용히 진행 금지)
- **네이버블로그 채널 전용 규칙(⭐ v1.4)**: 네이버블로그 발행일 후보에서 월요일 제외 (평일이지만 발행일로 쓰지 않음). 다른 채널(홈페이지블로그·카드뉴스 등)은 월요일 배치 가능

### 4단계: 우선순위 및 에피소드 정렬 (⭐ v1.5: 우선순위 규칙 추가)
- **1차 정렬(우선순위, ⭐ v1.5):** 콘텐츠의 "단계" 속성 값이 **"8.타이핑 요청"**인 항목을 최우선으로 가장 앞쪽(가장 이른 날짜)에 배치한다.
  - 이런 항목이 여러 개면 서로 간에도 5단계의 균등 간격 규칙을 그대로 적용해 순서대로 이른 날짜부터 분배한다 — 한 날짜에 몰아서 배치하지 않는다.
  - "단계" 속성이 없거나 값이 다르면 이 우선순위 규칙은 적용하지 않고 2차 정렬 기준만 따른다.
- **2차 정렬(에피소드 번호):** 우선순위가 같은 항목들끼리는 콘텐츠 제목에서 "1/10", "2/10" 같은 패턴을 자동 감지해 숫자 순서대로 정렬한다.

### 5단계: 균등 간격 배치
- 추출된 평일 수와 콘텐츠 개수를 기반으로 2~7일 범위 내에서 가능한 균등하게 배치

### 6단계: 멀티 채널 스케줄링
같은 주제를 여러 채널에 동시 배포할 때:
1. 메인 채널(네이버블로그) 발행일 → 날짜 A (월요일 제외 규칙 적용, 후보가 월요일이면 다음 평일로 이동)
2. 보조 채널(홈페이지블로그) 발행일 → 날짜 A + 1일 (평일 기준, 홈페이지블로그는 월요일도 가능)

예시: 네이버블로그 7/11(금) → 홈페이지블로그는 7/12(토)를 건너뛰고 7/14(월)

### 7단계: 노션 반영
- 각 콘텐츠의 "예상 발행일" 필드에 자동 입력, 에피소드 순서대로 배치, 멀티 채널이면 모든 채널 동시 반영

## 선택 정보

**제외할 공휴일**: 기본값은 `schedule.py` 의 `KR_HOLIDAYS` 테이블(설날·추석 연휴, 대체공휴일,
제헌절(2026 재지정) 등 전체). 사내 발행 제외일 등 공휴일 아닌 날을 빼려면 input.json 의
`extra_exclude` 에 날짜를 넣는다

**드라이런 모드**: "미리보기만 해줘"라고 하면 계산만 하고 노션에 반영하지 않은 채 결과를 먼저 보여준다. "반영해줘" 확인 후 최종 업데이트.

## 제한사항

- 노션 MCP 인증 필수 (필터 조회에는 jedi 도구가 아니라 인증된 Notion MCP 연결 필요)
- 월, 콘텐츠 구분 두 필터 필드만 사용 가능
- 에피소드 숫자가 "N/M" 형식이어야 자동 감지 가능

## 스킬이 하지 않는 것

- 기존 발행일 덮어쓰기 (새로 배정된 날짜만 입력)
- 콘텐츠 제목 수정, 노션 페이지 신규 생성 (기존 항목에만 작동)

## 막혔을 때

| 증상 | 조치 |
|---|---|
| 노션 조회에 카드가 0건 | 콘텐츠마스터 DB가 두 종류일 수 있음 — "필수 정보"의 데이터소스 ID가 맞는지, 이름이 비슷한 TEST용 DB를 잘못 보고 있지 않은지 확인 |
| Notion MCP 인증 안 됨 | 사용자에게 claude.ai 연결 계정에서 Notion 인증을 안내 |
| 에피소드 번호가 정렬되지 않음 | 제목이 "N/M" 형식이 아닐 수 있음 — 사용자에게 순서를 직접 확인 |
| 표준 규칙(다음날 시작)과 다른 시작일을 요청받음 | 임의로 바꾸지 말고, 표준 규칙과 다르다는 점을 먼저 사용자에게 확인 |

## 실제로 돌려본 결과 (검증)

- **엔노블 26년 7월** (2026-07-08 실행, v1.2): 네이버블로그 10개 + 홈페이지블로그 10개, 총 20개 페이지에 "예상 발행일" 자동 반영 완료. 에피소드 1/10~10/10 순서 정렬, 홈페이지블로그 = 네이버 +1일(토/일/공휴일 제외) 정상 동작 확인.
