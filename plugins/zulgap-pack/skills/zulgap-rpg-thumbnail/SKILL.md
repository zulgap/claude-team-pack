# RPG 썸네일 (1080x1080)

RED PASSPORT GLOBAL 블로그 글에 붙일 정사각 썸네일을 만든다.
**바뀌는 것은 제목 텍스트뿐이다.** 배경·색·서체·레이아웃은 브랜드 고정값이므로 건드리지 않는다.

다른 브랜드 썸네일 스킬과 달리 **배경 이미지 파일이 없다.** 배경을 코드로 그리므로
에셋을 내려받거나 캐시할 필요가 없고, 폰트만 있으면 어느 PC에서든 같은 결과가 나온다.

## 언제 쓰나

```
"/zulgap-rpg-thumbnail"
"RPG 썸네일 만들어줘"
"이 제목으로 레드패스포트 썸네일"
"네이버 카드에 썸네일 넣어줘"
```

## 안 되는 경우

- **다른 브랜드 썸네일** → 브랜드마다 전용 스킬이 따로 있다. 색과 레이아웃이 전부 다르다
- **유튜브 썸네일** → 비율(16:9)과 기획 방식이 다르다. 유튜브 전용 스킬로
- **본문에 들어갈 도식·삽화** → 이 스킬은 대표 이미지 한 장만 만든다

## 고정 사양 (바꾸지 않는다)

브랜드 정본의 팔레트만 쓴다.

| 요소 | 값 |
|---|---|
| 크기 | 1080 x 1080 |
| 배경 | Passport Navy `#1C2951` → `#0E162E` 세로 그라데이션 |
| 궤적 | Santa Red `#DC143C` 점선 호 (정본 시그니처 Star Trail) |
| 별 | Gold Star `#FFD700` — 궤적 끝에 배치 |
| 글자 | 흰색 · 한글 볼드 고딕 · 좌측 정렬 · 세로 중앙 |
| 하단 바 | Santa Red 짧은 막대 |

## 실행

```bash
python scripts/make_thumbnail.py --title "컨테이너|반납 지연료" --out thumb.png
```

- 줄바꿈은 `|` 로 직접 지정한다. 자동 분할은 의미 단위를 못 지킨다
- **`|` 는 2개까지(= 3줄)** 다. 넘으면 `[TOO-MANY-LINES]` 로 중단한다 — 넘치는 줄을 말없이 잘라내면 제목 일부가 빠진 채 완성된 것처럼 보인다

## 🔴 카피는 짧게 — 글자 크기에 하한이 있다

**네이버 검색결과는 썸네일을 약 110px로 줄여 보여준다.** 1080 기준 글자가 **147px 이상**이어야
거기서 15px이 되어 읽힌다. 스크립트가 이 하한을 스스로 검사한다.

- 미달이면 `[TOO-SMALL]` 을 찍고 종료코드 1로 끝나며 **PNG 를 만들지 않는다**
- 🔴 **실패는 산출물을 남기지 않는다.** 파일이 있으면 성공, 없으면 실패다 — 종료코드를 놓쳐도 결과가 뒤바뀌지 않게 한 것이다
- 🔴 **`[TOO-SMALL]` 이 뜨면 레이아웃·여백을 만지지 말고 카피를 줄인다.** 여백을 좁히면 궤적과 별이 가려져 브랜드가 사라진다

카피는 **글 제목을 그대로 넣지 말고 후킹 문구만** 넣는다. 검색 키워드를 첫 줄에 둔다.

- 좋음: `컨테이너|반납 지연료` · `THC가|두 번 나오는|이유`
- 나쁨: `컨테이너 반납 지연료, 하루 늦으면 얼마씩 붙나요` (한 줄에 다 넣어 하한 미달)

## 노션 카드에 붙일 때

파일로 업로드해 카드 안에서 바로 보이게 한다(`create-file-upload` → `markdown_source`).

🔴 **네이버는 외부 이미지 URL을 막는다.** 카드의 이미지는 붙여넣기용이 아니라 **내려받기용**이다.
카드 본문에 *"이미지를 내려받아 네이버 에디터에 직접 업로드하세요"* 를 반드시 적는다.

## 막혔을 때

| 증상 | 원인과 해법 |
|---|---|
| `[NO-FONT]` | 한글 볼드 폰트를 못 찾았다. `FONT_CANDIDATES` 에 그 PC의 폰트 경로를 추가한다 |
| `[TOO-SMALL]` | 카피가 길다. 줄이거나 줄을 나눈다 |
| `[TOO-MANY-LINES]` | `\|` 가 3개 이상이다. 3줄 이내로 |
| 글자가 뭉개져 보임 | 한글에 `stroke_width` 를 쓰지 말 것 — 자소 사이가 메워져 오히려 안 읽힌다. 굵기는 서체로만 낸다 |

🔴 **한글을 이미지 생성 모델에 그리게 하지 말 것.** 오탈자가 나고 재시도 비용이 크다.
이 스크립트는 글자를 직접 그린다.

## 실행 검증

만든 뒤 두 가지를 확인한다.

1. 스크립트가 출력한 **글자 크기가 147px 이상**인가 (출력 줄에 찍힌다)
2. **파일이 실제로 생겼나** — 실패는 산출물을 남기지 않으므로 파일 존재가 곧 성공이다

## 변경 이력

**2026-08-09 — 신설 (v1.0.0)**
RPG 네이버 재가공 3편(12·13·14편)에 붙일 썸네일이 필요해 만들었다. 기존 브랜드 썸네일 스킬 3종은
전부 배경 PNG를 따로 두는 방식인데 RPG는 그 에셋이 없어, 배경을 코드로 그리는 쪽을 택했다.
색은 지어내지 않고 브랜드 정본의 팔레트만 썼다. 글자 크기 하한 147px 은 다른 브랜드 스킬의
실측 근거를 그대로 가져온 것이다.
