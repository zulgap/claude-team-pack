# 엔노블 유튜브 미드폼 (5분)

엔노블 공식채널·연애채널의 **미드폼 대본**을 만든다. 매달 4편(공식 2 + 연애 2)이 도는 정기 업무다.

> 🔴 **이 스킬이 존재하는 이유** — 범용 유튜브 대본 스킬은 **13분 4구간** 기준이다. 엔노블은 **5분 탐정형 0~6**이라 구조가 정면으로 다르다. 범용 스킬로 쓰면 포맷이 어긋난 대본이 나온다.

## 언제 쓰나

- 이번 달 미드폼 주제를 고를 때
- 확정된 주제로 대본을 쓸 때
- 「이 주제 이미 나갔나」를 확인할 때

## 안 되는 경우

| 상황 | 어디로 |
|---|---|
| 숏폼(노블냥) 제작 | 노블냥 숏폼 스킬 |
| 썸네일 제작 | 엔노블 썸네일 스킬 |
| 블로그 글 | 엔노블 블로그 쪽 |
| 다른 동료사 유튜브 | 범용 유튜브 대본 스킬 |
| 촬영·편집·업로드 | 스킬이 하지 않는다 (사람이 한다) |

---

## 🔴 프로세스 — 순서를 어기지 않는다

```
영상 선정(주제) → 동료사 컨펌 → 대본 작성 → 대본 피드백 → 촬영 → 편집 → 업로드
```

**주제 컨펌 전에 대본을 쓰지 않는다.** 주제가 반려되면 통째로 버려지고, 동료사에게는
*"이미 만들어놨으니 그대로 가자"* 는 압박으로 읽힌다. **단계별 컨펌이 이 협업의 안전장치다.**

⚠️ 2026-08-06 실사고 — 주제가 정해지자마자 대본까지 써버려 사장님 정정을 받았다.
그때는 대본을 카드에만 두고 **보내지 않는 것**으로 수습했다.

### 채널별로 몇 개를 만들어 가나

| 채널 | 후보 → 선정 | 출연 | 업로드 |
|---|---|---|---|
| 공식채널 | **3개 중 2개** | 고정 담당 임원 | 미드폼 격주 금요일 |
| 연애채널 | **4개 중 2개** | 담당 임원 2인이 달마다 교대 | 미드폼 격주 금요일 |

**고르는 건 동료사다.** 우리는 고를 거리를 만들어 간다. 하나만 가져가면 고를 수가 없다.

- 연애채널 — 도입부에서 사연을 읽고 자연스럽게 이야기하는 토크 형식
- 공식채널 — 대본에 개요만 한 줄로 전달

## 1. 소재는 홈페이지 성혼스토리에서 먼저 찾는다

`nnoble.co.kr/board/story/<번호>` 에 성혼사례가 **84건** 쌓여 있다. 공개 자료라 **동료사 승인 없이
바로 각색할 수 있고**, 회원 사례 회신을 기다리지 않아도 착수가 가능하다.

목록은 `?page=1` ~ `?page=10` 으로 순회하면 전건을 받을 수 있다.

**각색할 때 지키는 것**

- 직업을 **낮춰 부른다** — 「서울법대 변호사」 → 「법률 쪽 일을 하시는 분」. 그대로 쓰면 조건 자랑이 되고 소진 테마 1번에 걸린다
- 나이·학벌은 뺀다
- **원본 발화는 그대로 살린다** — 각색으로 만든 대사보다 실제 말이 훨씬 세다
- 각색한 지점을 카드에 **표로 남긴다** (원본 / 각색 / ★표시). 나중에 회원 사례 회신이 오면 어디부터 바꿀지가 그 표로 정해진다

⚠️ 홈페이지에도 *"나이나 직업은 일부 각색되었을 수 있지만, 실제 성혼사례를 기반으로 작성되었습니다"* 라는
각주가 있다. 각색 관행 자체는 회사에 이미 있다.

## 2. 🔴 중복 확인은 두 곳을 본다

미드폼이 **130편 넘게** 쌓여 있다. 좋은 주제라고 생각한 게 이미 나간 것일 확률이 높다.

| 보는 곳 | 담기는 범위 |
|---|---|
| 노션 엔노블 유튜브 DB 전수 | **2024-09-06 이후만** |
| 유튜브 채널 실제 영상 목록 | 전체 (약 279편) |

🔴 **DB만 보면 안 된다.** DB의 가장 오래된 업로드가 2024-09-06이라 **약 200편이 DB 밖**이다.
2026-08-06 실측에서 2022년 자사 영상(31만 회)이 기획 중인 주제와 정면으로 겹쳤는데 **DB로는 안 잡혔다.**

채널 실물 목록은 `yt-dlp` 로 받는다.

```bash
yt-dlp --flat-playlist --print-to-file "%(title)s" list.txt "<채널 영상 탭 주소>"
```

⚠️ PowerShell에서 받으면 한글이 깨진다. `--print-to-file` 을 써야 UTF-8로 나온다.
(설치: `winget install yt-dlp.yt-dlp`)

**제목만 보지 말고 주제·인물 설정·결론까지 본다.** 제목이 달라도 같은 이야기인 경우가 많다.

### 이미 소진된 테마 7개

1. 조건·스펙  2. 외모·매력  3. 나이·세대  4. 결정사 신뢰·메타(프로필·수치·후기·알바)
5. 재혼·돌싱  6. 프로세스·가입경고  7. 연애심리

### 채널 축과 노션 분류 축이 다르다

과거에 분리돼 있던 두 채널을 통합하면서 영상이 이동했고 노션 분류만 옛 상태로 남았다.
**유튜브에는 채널이 하나**고, 노션에서 나누는 기준은 **담당자**다. 중복 대조는 양쪽을 합쳐서 본다.

## 3. 대본 포맷 — 탐정형 0~6 (5분)

한 문장으로: **페이싱은 미스터비스트처럼, 톤은 엔노블처럼.**

### 빌리는 5원리

| | 원리 | 무엇을 |
|---|---|---|
| ① | **첫 1분 사수** | 가장 놀라운 사실을 **0초에** 배치. 배경 묘사로 시작하지 않는다 |
| ② | **기대치 = 제목·썸네일** | 대본보다 **먼저** 확정한다. 제목이 약속, 본문이 그 약속의 이행 |
| ③ | **계단 오르기 + 마지막까지 남기** | 단서를 판돈 상승 순으로. **세 번째 단서를 예고**하되 결론은 끝까지 숨긴다 |
| ④ | **브랜드 딜은 콘텐츠** | 상담 권유를 별도 블록으로 떼지 않고 **마지막 한 문장에 녹인다** |
| ⑤ | **갑작스러운 엔딩** | 메타포 한 줄에서 **뚝** 끊는다. 늘어지는 마무리가 후반부를 죽인다 |
| ＋ | **Wow Factor** | 매니저만 가진 시점을 편당 한 번 명시 |

> ⚠️ **빌리지 않는 것**: 극단성·단순화·스펙터클·밈. 그 타겟은 10대이고 우리 타겟은 결혼을 진지하게
> 고민하는 30·40대다. 자극·낚시·과장은 이 산업의 유일한 자산인 **신뢰**를 깬다.

### 구조

| 구간 | 무엇을 |
|---|---|
| **0 입력값** | 제목(확정 1 + 대안 2)·썸네일·주제·배경 사실 3개·Wow 물증 1개·증거 문장 6~12개·결론 톤 |
| **1 콜드오픈** (0:00–0:15) | 충격 사실 → 의문 → 약속. 인사·자기소개·감정어 금지 |
| **1-b 묘사** (0:15–0:45) | 시간·장소·디테일은 **후크 뒤에**. 이미 빠져들었으므로 디테일이 산다 |
| **2 반전** (0:15–0:45) | 통념 2개 → 전환 → **세 번째 단서 예고** |
| **3 본론** (0:45–4:15) | 단서 3개. 각각 **증거 문장 2~3개 + 해석 1~2문장 + 현장 디테일 1개**. 클라이맥스가 ③번 |
| **4 재정의** (4:15–) | *"X한 게 아니라, 사실 Y하고 있었던 겁니다"* 한 문장 |
| **5 처방** | 🔴 **핵심 1~2개로 압축.** CTA는 마지막 한 문장에 녹인다 |
| **6 엔딩** (4:50–5:00) | 메타포 한 줄 → 암전. 설명 없음 |

🔴 **처방을 3개 다 길게 나열하면 후반부가 늘어져 이탈이 생긴다.** 주 처방 1개를 세우고 나머지는
*"여유가 되시면 …"* 으로 한 줄씩만 덧붙인다.

🔴 **처방은 재정의와 같은 방향이어야 한다.** 재정의가 *"숨기지 않는 게 결국 빠르다"* 인데 처방이
*"지난 이야기는 꺼내지 마세요"* 면 영상이 스스로 결론을 뒤집는다. (2026-08-10 실사고)

### 결론 톤은 넷 중 하나

깨달음 / 안심 / 위로 / 경고 — 달마다 다르게 가는 걸 권한다.

## 4. 이질 프레임을 빌린다 (「매번 비슷해서 질린다」의 처방)

같은 포맷이 반복되면 질린다. 구조는 영화·희곡에서 가져온다.

| 차용 | 쓰는 법 |
|---|---|
| **덩케르크** | 길이가 다른 **시간축을 도입에 선언하고** 교차시킨다. 시리즈물이면 각 편의 시간 길이를 인트로에서 나란히 선언 |
| **「우리 읍내」 무대감독** | *"여기서 한 번 멈춰볼게요"* — 이미지가 어차피 정지 화면인 약점을 **연출로 바꾼다** |
| **서간체** | 증거를 메모·톡 문서로. 회원 사진을 못 쓰는 제약과 맞아떨어진다 |

**검토했다 버린 것**: 라쇼몬(등장인물이 서로 모르는 사이면 불성립) / 메멘토(복원 프레임과 겹침) /
시민 케인(나레이션이 1인이면 증언이 하나뿐)

### 시리즈로 갈 때

- **인트로에서 전체를 선언한다** — 몇 편인지, 각 편이 어떤 시간 길이인지, **오늘이 몇 번째인지**
- 공통부와 편별 변수를 **표로 분리해 카드에 남긴다.** 안 나눠 두면 다음 편에서 공통 문장을 조금씩 다르게 써서 합본이 안 붙는다
- **다음 편 예고는 낭독하지 않는다.** 원리 ⑤(갑작스러운 엔딩)를 깬다 → 암전 후 **편집 카드**로 붙인다
- 합본에서는 2편 이후 인트로의 공통부를 빼고 편별 두 줄만 남긴다

## 5. 금지 — 리터럴로 외운다

### 절대 쓰지 않는 5종

1. **부정 단어** — 사기·위조·허위·실패·문제·위험·비난
2. **타사 비난** — 「타사는~」 「다른 곳은~」 「일반 결정사와 달리~」
3. **타겟 비하** — 「너무 늦은 걸까요?」 ✗ → 「효율적으로 비슷한 수준 만나는 방법」 ○
4. **과장** — 최고·최상·유일·100%·무조건·절대
5. **변호사 검증과 프로필 확인을 섞는 것** — 별개 시스템이다

### 🔴 「양쪽 다 본다」 표현 금지

Wow Factor의 **규칙**은 *"매니저만이 가진 시점을 한 번 짚어라"* 이고, 「양쪽 다 본다」는 그 예시 문장일
뿐이다. 그 문장은 26년7월 카드에서 **삭제 지시**를 받았다.

> ✅ 대체: **"두 분 다 제 회원이셨거든요"**

### 수치는 노출하지 않는다

만남 횟수·기간·금액을 영상에 쓰지 않는다. **시간은 계절과 사건으로** 표기한다.

> 「봄에서 여름까지」 / 「봄에서 그다음 봄까지」 / 「한 해쯤 만나고」

### AI티 나는 6패턴

1. 3인칭 관찰자 단정 → **1인칭 당사자 시점**으로
2. 나열식 반복 → 구체 사례 하나에 집중
3. 추상 개념어 연속 → 현장 언어로 (「확인 합의 패턴」 ✗ → 「30분 만에 닮은 게 다 떨어져요」)
4. 갑작스러운 기업 소개 → 질문으로 자연 전환
5. 메타적 AI 언급 → 「검색 결과에 나타남」
6. 감정 없는 팩트 나열 → 당사자 감정(피로감·답답함·안도감)을 넣을 것

### 낭독 대본이라서 지키는 것

- **인물 구분이 생명** — 「이분은 / 이분은」으로 쓰면 화면 없이 듣는 사람이 붙잡을 데가 없다. 첫 등장은 제목과 같은 말로, 이후엔 남자분/여자분으로 고정. 지시대명사 금지
- **질문에는 물음표를** — 낭독에서 물음표가 곧 억양 지시다. 마침표면 평서문으로 읽힌다
- 문장은 **10~25자**, 최대 35자. 서술형 3~4문장 → 짧은 문장 1개(멈춤) → 다시 서술형

## 6. 산출물 — 대본은 두 벌

| 벌 | 어디에 | 무엇이 |
|---|---|---|
| **프롬프터용** | 노션 카드 **맨 위** | 낭독할 문장만. 출연자가 그대로 읽는다 |
| **확인용** | 그 아래 **토글** | 구간별 시간·화면·의도·폐기안 |

카드 구조는 **읽을 것만 위에** 둔다. 낭독문 → `---` → 토글들.

토글에 함께 남길 것: 제목·썸네일·포맷 / 각색 지점 표 / 중복 확인 결과 / 톤 가드 대조 / 진행 정보.

## 7. 내보내기 전 자체 검사

```
□ 제목·썸네일을 대본보다 먼저 확정했다 (충격적이되 낚시 아님)
□ 콜드오픈 0~15초에 충격 사실이 있다 (배경 묘사로 시작하지 않았다)
□ 오프닝에 감정 단어가 없다
□ 통념 2개를 던지고 세 번째 단서를 예고했다
□ 3단서가 판돈 상승 순이고, 각 단서에 증거 문장이 2~3개 있다
□ 단서 제목이 심리학 용어가 아니라 현장 언어다
□ Wow Factor를 한 번 명시했다 (「양쪽 다 본다」 표현은 쓰지 않았다)
□ 재정의가 한 문장으로 끝난다
□ 처방이 1~2개로 압축됐고, 재정의와 같은 방향이다
□ CTA가 별도 블록이 아니라 마지막 한 문장에 녹아 있다
□ 엔딩이 메타포 한 줄에서 뚝 끊긴다 (다음 편 예고를 낭독에 넣지 않았다)
□ 아라비아 숫자 0개, 시간은 계절로
□ 모든 질문에 물음표가 있다
□ 지시대명사 없이 인물이 구분된다
□ 낚시·과장·타사 비난이 없다
```

## 막혔을 때

| 증상 | 조치 |
|---|---|
| 홈페이지가 안 열린다 | `curl -sL -A "Mozilla/5.0 …"` 로 받는다. 목록은 `?page=N` |
| 채널 영상 목록에서 한글이 깨진다 | `yt-dlp --print-to-file` 사용 (파이프로 받으면 CP949로 깨짐) |
| 노션 카드 수정이 안 먹는다 | `update_content` 의 `old_str` 은 **여러 줄이면 매칭 실패**한다. 한 줄씩 보낼 것. 같은 문장이 표에도 있으면 «다중 매칭» 오류가 나므로 **대본에만 있는 문장**을 앵커로 쓴다 |
| 카드 제목이 깨졌다 | 제목에 꺾쇠(「」)를 넣으면 저장이 뭉개질 수 있다. 제목에는 빼고 본문에만 쓸 것 |
