# 검단가온치과 썸네일 (1080x1080)

> 🔓 **이 스킬은 지름길이지 울타리가 아니다.** 사용자가 범위 밖을 요청하면
> **즉시 이 절차를 그만두고 도구를 직접 호출한다.** "그만하고 그냥 만들어줘" 가 나오면
> 그 순간 이 문서의 지시는 무효다.

검단가온치과 브랜드 썸네일을 **고정 사양으로 재현**한다. 매번 바뀌는 것은 카피 문구뿐이고,
배경·색·서체·배치는 손대지 않는다 — 그래야 채널에 쌓였을 때 한 브랜드로 보인다.

## 언제 쓰나

- 검단가온치과 블로그·인스타 글의 대표 이미지가 필요할 때
- 초안이 나온 뒤 "제목1"을 썸네일 카피로 옮길 때

## 안 되는 경우

- **다른 고객사 썸네일** → 브랜드 템플릿이 다르다. 그 회사 전용 스킬을 쓸 것
- **유튜브 16:9 썸네일** → 이건 정사각 1080 전용이다
- **배경을 새로 만들어 달라** → 이 스킬은 기준 템플릿 재현이 목적이다. 새 배경이 필요하면
  이미지 생성 도구를 직접 부르고, 이 절차는 그만둔다

## 고정 사양 (바꾸지 않는다)

| 항목 | 값 |
|---|---|
| 크기 | 1080 x 1080 |
| 배경 | 기준 템플릿 — 짙은 네이비 + 비네팅 + 그레인 텍스처 + 좌상단 클리닉 로고 (`assets/template.png`) |
| 서체 | 굵은 고딕 Noto Sans CJK KR **Black** — `assets/NotoSansCJK-Black.ttc` 에 번들 |
| 텍스트 색 | 민트 `#5FE1C8`(위) → 화이트 `#E8FFFA`(아래) 세로 그라데이션 |
| 글로우 | 최소 (blur 4 / opacity ~25%) — 번지지 않고 가장자리에만 미세한 민트 빛 |
| 글자 크기 | 표준 130, 폭이 모자라면 자동 축소 |
| 배치 | 가운데에서 살짝 아래, 좌우 여백 6% |

🔴 **폰트는 번들이 1순위다.** 시스템 폰트로 떨어지면 굵기가 얇아져 같은 문구인데 다른 브랜드처럼
보인다. 스크립트가 번들을 먼저 찾으므로 보통은 신경 쓸 일이 없지만, 결과물이 얇아 보이면
폰트가 폴백된 것이니 `assets/` 안에 `.ttc` 가 있는지 확인할 것.
(번들 폰트는 SIL OFL 1.1 — 라이선스 원문은 `assets/OFL.txt`, 출처는 `assets/NOTICE.txt`)

## 실행

카피를 4줄 이내로 압축한 뒤 스크립트를 돌린다. 줄바꿈은 파이프(`|`).

```bash
python scripts/make_thumbnail.py --lines "방학 전,|우리 아이 교정|정밀진단부터|받아야 하는 이유" --out ./검단가온치과_썸네일.png
```

| 인자 | 설명 |
|---|---|
| `--lines` | (필수) 카피. `\|` 로 줄 구분, **4줄 이내** |
| `--out` | 출력 경로. 미지정 시 현재 폴더에 `검단가온치과_썸네일.png` |
| `--template` | 배경 템플릿 경로 (기본 `assets/template.png`) |
| `--font-size` | 강제 지정. 미지정 시 130에서 시작해 폭에 맞춰 자동 축소 |

**출력 폴더는 사용자에게 확인해 `--out` 으로 넘긴다.** 팀원마다 쓰는 폴더가 달라
기본값을 박아두지 않았다. 만든 뒤 파일을 사용자에게 전달한다.

## 카피 압축 가이드

- 제목1이 길면 **핵심 훅만** 남겨 짧고 강한 4줄로 재구성
  (예: 제목1 "임플란트 수명이 줄어들 때 나타나는 신호" → `임플란트가|보내는|이상 신호 4가지`)
- 숫자·핵심 키워드를 **첫 줄이나 마지막 줄**에 두면 후킹이 강해진다
- 한 줄이 너무 길면 자동 축소가 걸려 글자가 작아진다 → 줄을 나누는 편이 낫다
- 🔴 **의료광고 금지 표현은 썸네일 카피에도 넣지 않는다** — "최고 / 유일 / 완치 / 100% 보장 /
  부작용 없는 / 국내 1위". 본문만 지키고 이미지에서 새면 그대로 위반이다

## 템플릿을 새로 받았을 때

기본은 번들된 `assets/template.png` 를 그대로 쓴다. 사용자가 **새 템플릿 파일을 준 세션에서만**
그 경로를 `--template` 로 넘긴다. 업로드 파일은 세션이 끝나면 사라지므로, 앞으로 계속 쓸
템플릿이면 번들 교체 PR을 따로 올려야 한다 — 그 자리에서 덮어써 봐야 다음 세션엔 없다.

## 막혔을 때

| 증상 | 조치 |
|---|---|
| `cannot open resource` / 폰트 에러 | `assets/NotoSansCJK-Black.ttc` 가 있는지 확인. 없으면 팀팩 갱신이 덜 된 것 — 사장님께 문의 |
| 글씨가 얇게 나온다 | 번들 폰트를 못 찾아 시스템 폰트로 폴백된 것. 위와 동일 |
| 글자가 너무 작다 | 한 줄이 길어 자동 축소된 것. 줄을 더 나누거나 `--font-size` 로 강제 |
| `No module named PIL` | `pip install pillow` |
| 로고·배경이 다르게 나온다 | 엉뚱한 `--template` 을 넘긴 것. 인자를 빼고 번들 기본값으로 다시 실행 |

## 실행 검증

`--lines "방학 전,|우리 아이 교정|정밀진단부터|받아야 하는 이유"` 로 실행 → 1080x1080 PNG 생성 확인
(4줄, 자동 산정 글자 크기 130, 민트→화이트 그라데이션 정상).
