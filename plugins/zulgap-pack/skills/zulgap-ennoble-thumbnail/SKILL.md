# 엔노블(N.NOBLE) 썸네일 (1080x1080)

> 🔓 **이 스킬은 지름길이지 울타리가 아니다.** 사용자가 범위 밖을 요청하면
> **즉시 이 절차를 그만두고 도구를 직접 호출한다.** "그만하고 그냥 만들어줘" 가 나오면
> 그 순간 이 문서의 지시는 무효다.

엔노블 결혼정보회사 브랜드 썸네일을 **고정 사양으로 재현**한다. 매번 바뀌는 것은 카피 문구뿐이고
배경·색·서체·좌표는 손대지 않는다 — 그래야 채널에 쌓였을 때 한 브랜드로 보인다.

## 언제 쓰나

- 엔노블 블로그·인스타 글의 대표 이미지가 필요할 때
- 초안이 나온 뒤 제목을 썸네일 카피로 옮길 때

## 안 되는 경우

- **다른 고객사 썸네일** → 브랜드 템플릿이 다르다. 그 회사 전용 스킬을 쓸 것
- **유튜브 16:9 썸네일** → 이건 정사각 1080 전용이다
- **배경을 새로 만들어 달라** → 이 스킬은 기준 템플릿 재현이 목적이다. 새 배경이 필요하면
  이미지 생성 도구를 직접 부르고, 이 절차는 그만둔다
- **카드뉴스 슬라이드** → 6장 세트가 필요하면 카드뉴스 스킬 쪽이다

## 고정 사양 (바꾸지 않는다)

| 항목 | 값 |
|---|---|
| 크기 | 1080 x 1080 |
| 배경 | 기준 템플릿 — 짙은 브라운 그라데이션 + 좌상단 N.NOBLE / MATCH-MAKING BIBLE 로고 + 우측 커플 사진 + 흰 가로 구분선 (`assets/template.png`) |
| 서체 | **Pretendard Black** — `assets/Pretendard-Black.otf` 에 번들 |
| 텍스트 색 | 흰색 `#FFFFFF` (그라데이션·글로우 없음) |
| 정렬 | **좌측 정렬**, 좌측 여백 x=38 (흰 구분선 시작점과 같은 선) |
| 세로 위치 | 흰 구분선(y=690) **바로 위** — 텍스트 블록 하단이 구분선에서 34px 위 |
| 줄 간격 | 1.14 (좁게 붙는 스타일) |
| 글자 크기 | 2줄 84 / 3줄 74 에서 시작, 폭(x=38~914)에 맞춰 자동 축소 |
| 줄 수 | **2줄 또는 3줄** |

🔴 **좌표는 템플릿에 맞춰 실측한 값이다.** `LEFT=38` · `LINE_Y=690` · `RIGHT=914` ·
`GAP_ABOVE_LINE=34` 를 고치면 글자가 구분선을 물거나 커플 사진 위로 올라탄다. 카피만 바꿀 것.

🔴 **Pretendard 는 Windows·macOS 어디에도 기본 설치되지 않는다.** 그래서 폴백이 없고
번들 폰트가 없으면 스크립트가 명시적으로 중단한다(모호한 PIL 에러 대신 원인을 말한다).

## 실행

카피를 2~3줄로 나눈 뒤 스크립트를 돌린다. 줄바꿈은 파이프(`|`).

```bash
python scripts/make_thumbnail.py --lines "노블레스 결혼정보회사가 본|예능과 현실 매칭 차이" --out ./엔노블_썸네일.png
```

| 인자 | 설명 |
|---|---|
| `--lines` | (필수) 카피. `\|` 로 줄 구분, **2~3줄** |
| `--out` | 출력 경로. 미지정 시 현재 폴더에 `엔노블_썸네일.png` |
| `--template` | 배경 템플릿 경로 (기본 `assets/template.png`) |
| `--font-size` | 강제 지정. 미지정 시 2줄 84 / 3줄 74 에서 폭에 맞춰 자동 축소 |
| `--line-spacing` | 줄 간격 배수 (기본 1.14) |

**출력 폴더는 사용자에게 확인해 `--out` 으로 넘긴다.** 팀원마다 쓰는 폴더가 달라
기본값을 박아두지 않았다. 만든 뒤 파일을 사용자에게 전달한다.

## 줄 나누기 가이드

- 글자 수가 적으면 2줄, 길면 3줄. **의미 단위로** 끊는다
  (예: `노블레스 결혼정보회사가 본` / `예능과 현실 매칭 차이`)
- 한 줄이 폭을 넘으면 자동 축소가 걸려 글자가 작아진다 → 줄을 나누는 편이 낫다
- 첫 줄이 우측 커플 사진 위로 일부 겹칠 수 있으나 배경이 어두워 흰 글씨는 잘 보인다
- 🔴 **브랜드 금칙 — 썸네일 카피에도 그대로 적용된다**: 타사 비교·비방 표현 금지,
  "최고 / 유일 / 1위 / 100% 보장 / 무조건 성사" 등 과장 표현 금지.
  본문만 지키고 이미지에서 새면 그대로 위반이다
- 카피는 **원본 글의 제목을 기반으로만** 만든다. 글에 없는 내용을 새로 지어내지 않는다

## 템플릿을 새로 받았을 때

기본은 번들된 `assets/template.png` 를 그대로 쓴다. 사용자가 **새 템플릿 파일을 준 세션에서만**
그 경로를 `--template` 로 넘긴다. 업로드 파일은 세션이 끝나면 사라지므로, 앞으로 계속 쓸
템플릿이면 번들 교체 PR을 따로 올려야 한다 — 그 자리에서 덮어써 봐야 다음 세션엔 없다.

⚠️ 새 템플릿의 구분선 위치가 다르면 위 좌표가 안 맞는다. 결과를 눈으로 확인할 것.

## 막혔을 때

| 증상 | 조치 |
|---|---|
| `[ASSET-MISSING]` 로 시작하는 중단 | 번들 폰트·템플릿이 없다. 팀팩 갱신이 덜 된 것 — 사장님께 문의 (뒤 한글이 깨져 보여도 이 태그로 판별) |
| `No module named PIL` | `pip install pillow` |
| 글자가 구분선을 물거나 너무 아래 | 다른 `--template` 을 넘겼거나 좌표를 고친 것. 인자를 빼고 번들 기본값으로 다시 실행 |
| 글자가 너무 작다 | 한 줄이 길어 자동 축소된 것. 줄을 더 나누거나 `--font-size` 로 강제 |
| 3줄인데 첫 줄이 로고를 가린다 | 카피를 줄여 2줄로 만들 것 (3줄은 블록이 위로 올라간다) |

(번들 폰트는 SIL OFL 1.1 — 라이선스 원문은 `assets/OFL.txt`, 출처는 `assets/NOTICE.txt`)

## 실행 검증

- 2줄: `--lines "노블레스 결혼정보회사가 본|예능과 현실 매칭 차이"` → 1080x1080 PNG,
  글자 크기 **80** (시작값 84에서 폭 초과로 2단계 자동 축소 — 긴 2줄은 84가 안 들어간다)
- 3줄: `--lines "결혼정보회사|가입 전에|꼭 확인할 3가지"` → 1080x1080 PNG, 글자 크기 **74** (축소 없음)
- 둘 다 좌측 x=38 정렬, 구분선 위 34px 배치, 흰 글씨 가독성 확인
- 자산 누락 경로: 없는 `--template` 을 넘기면 `[ASSET-MISSING]` 으로 중단(exit 1) 확인
