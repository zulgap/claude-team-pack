# 개인정보 처리방침 — 줄갭 팀팩(claude-team-pack)

> 대상: 이 패키지를 설치해 쓰는 **줄갭 임직원·협력자**
> 공개일: (미정 — 공지와 함께 확정) · 최종 개정: 2026-08-19 (초안)
> 근거: 개인정보 보호법 §15②·§21·§26②·§28조의8·§30

> 🔴 **이 문서는 초안이다.** 아래 `⟪확인 필요⟫` 표시가 남아 있는 동안에는 **공개·공지하지 않는다.**
> 그 칸은 사람이 정할 값(보호책임자·연락처·주소)이라 지어내지 않았다.

## 1. 무엇을 모으는가 (수집 항목)

이 패키지를 설치하면 **Claude Code 훅 2개**(`hooks/prompt-capture.js` · `hooks/response-capture.js`)가
아래를 줄갭 서버로 보낸다. 서버 저장 테이블은 `prompt_log` 하나이고 칸은 13개다.

| 보내는 것 | 실물 | 비고 |
|---|---|---|
| **내가 입력한 프롬프트 전문** | `prompt_text` | 99,000자에서 잘린다 |
| **AI 응답 전문** | `response_text` | 190,000자에서 잘린다 |
| 세션 식별자 | `session_uuid` | Claude Code 가 만든 UUID |
| 대화 턴 식별자 | `turn_uuid` | `세션id + 프롬프트` 해시(중복 전송 방지용) |
| 시각 | `ts` · `response_ts` · `created_at` | |
| **작업 폴더 경로** | `project_hint` (= 실행 시점 `cwd`) | 🔴 윈도우 경로라 **PC 계정명이 들어갈 수 있다**(예: `C:\Users\<이름>\...`) |
| 출처 | `source` = `claude_code` | |
| **누가 보냈는지** | `actor_id` · `is_owner` · `tenant_id` | 본문에 담기지 않고, **인증 토큰으로 서버가 판별**한다 |

**안 보내는 것**: 파일 내용 자체 · 화면 캡처 · 음성 · 위치.
토큰이 없는 PC(미설치·미로그인)는 아무것도 보내지 않는다(훅이 조용히 종료한다).

⚠️ **프롬프트에 적은 것은 그대로 저장된다.** 주민등록번호·계좌·카드번호·비밀번호는 **프롬프트에 쓰지 말 것.**
(수집 단계 마스킹은 아직 없다 — 아래 §8 「예정된 개선」)

## 2. 왜 모으는가 (수집·이용 목적)

1. **도구를 고치기 위해** — 어떤 요청이 실패하거나 헛도는지 실제 사례로 확인
2. **판단을 결정론으로 승격하기 위해** — 같은 일을 AI 가 매번 다시 판단하지 않도록 사례를 자산으로 축적
3. **비용·사용량 파악** — 어느 작업에 얼마가 드는지
4. **과거 작업 회상** — 「전에 이거 어떻게 했지」에 답하는 검색

목적 외 이용은 하지 않는다. **인사 평가·근태 감시에 쓰지 않는다.**

## 3. 얼마나 보관하는가 (보유·이용 기간)

**6개월.** 이후 파기한다(§21).

- 확정: 2026-08-19
- 🔴 **자동 파기(TTL)는 아직 구현 전이다.** 구현 전까지는 요청 시 수동 삭제로 처리한다.
- 실측 2026-08-19: 현재 최고령 기록 51일 — 도입 시점에 삭제되는 기록은 없다. 첫 자동 파기는 2026년 12월경.

## 4. 거부할 수 있는가 (동의 거부권과 불이익)

**거부할 수 있다.** 거부하면 **프롬프트·응답 「본문」을 수집하지 않고**, 실행 시각·사용 도구 같은 **메타만** 남는다.

- 방법: ⟪확인 필요 — 신청 창구⟫ 에 말하면 그 PC 의 본문 수집을 끈다.
  (자동 opt-out 스위치는 아직 없다 — 아래 §8)
- **거부에 따른 불이익은 없다.** 도구·스킬은 그대로 다 쓸 수 있다.
- 이미 쌓인 내 기록의 **열람·정정·삭제**도 같은 창구로 요청할 수 있다(§35~§37).

## 6. 국외로 보내는가 (국외이전 — §28조의8②)

**보낸다.** 위 수탁자가 국내 사업자가 아니다. 법 §28조의8② 가 요구하는 5가지를 밝힌다.

| 항목 | 내용 |
|---|---|
| ① 이전되는 항목 | §1 의 수집 항목 전부 |
| ② 이전되는 국가·시기·방법 | 미국(그 외 리전은 §5 표) · 이용 시점 즉시 · HTTPS 전송 |
| ③ 이전받는 자 | §5 표의 수탁자 |
| ④ 이용 목적·보유 기간 | §2 목적 · 각 사 정책에 따르되 줄갭 보유는 §3(6개월) |
| ⑤ 거부 방법·효과 | §4 와 동일. 거부 시 본문이 국외로 나가지 않는다 |

이 방침을 공개함으로써 §28조의8① 3호 가목(처리방침 공개)에 따른 이전 근거를 갖춘다.

## 7. 안전조치 (§29)

- 전송 구간 HTTPS · 토큰 인증(`Authorization: Bearer`)
- 회사(tenant)·사용자(actor) 단위 격리 — 남의 회사 기록은 조회되지 않는다
- 서버 접근은 운영 담당자로 제한
